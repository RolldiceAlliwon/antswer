## **스태틱 메시 반사가 이상하게 보이는 문제**

**특정 스태틱 메시의 반사가 어둡게 나오거나 노이즈가 생기는 현상은 탄젠트 정밀도 문제 때문일 수 있습니다.**

#### **해결 방법**

```
문제가 되는 Static Mesh 에셋을 엽니다
	↓
Details 패널
	↓
LOD0 - Build Settings
	↓
Use High Precision Tangent Basis를 Enable로 설정합니다.
```
#### **추가 설명**

**탄젠트 베이시스(Tangent Basis)는 노멀 맵이 적용되는 방식을 결정하는 좌표계입니다. 기본 정밀도에서는 메모리를 절약하기 위해 낮은 정밀도를 사용하지만, 이로 인해 반사나 라이팅 계산에서 미묘한 오차가 발생할 수 있습니다.**

**High Precision Tangent Basis를 활성화하면 더 정확한 계산이 가능하지만, 메시 데이터 크기가 약간 증가합니다. 주로 히어로 에셋이나 반사가 중요한 오브젝트에 적용하는 것이 좋습니다.**

## **머티리얼 형태가 깨져 보이는 문제**

**복잡한 UV를 가진 메시에서 머티리얼이 왜곡되거나 이음새가 보이는 문제는 UV 정밀도 부족 때문입니다.**

#### **해결 방법**

```
Static Mesh 에셋창을 엽니다.
	↓
Details 패널 
	↓
LOD0 - Build Settings
	↓
Use Full Precision UVs를 Enable로 설정합니다.
```

#### **추가 설명**

**언리얼 엔진은 기본적으로 메모리 효율을 위해 UV 좌표를 16비트 정밀도로 저장합니다. 하지만 매우 큰 메시나 복잡한 UV 레이아웃에서는 이것이 부족할 수 있습니다.**

**Full Precision UVs를 활성화하면 32비트 정밀도를 사용하여 더 정확한 텍스처 매핑이 가능하지만, 메시 데이터 크기가 증가합니다. 대형 건축물이나 정밀한 텍스처 배치가 필요한 에셋에 적용하시기 바랍니다.**

## **반사 표면에 Area Light가 보이는 문제**

**실제 조명 기구가 없는 곳에 배치한 Area Light가 반사면에 그대로 보이면 사실성이 떨어집니다.**

#### **해결 방법**

```
해당 Light 액터 선택
	↓
Details 패널 
	↓
Light → Advanced
	↓
Specular Scale을 0으로 설정합니다.
```

#### **추가 설명**

**Specular Scale은 반사광(스페큘러)의 강도를 조절하는 파라미터입니다. 0으로 설정하면 해당 라이트가 반사면에 나타나지 않으면서도 디퓨즈 라이팅은 그대로 유지됩니다.**

**하지만 더 좋은 접근은 실제 조명 기구가 있는 위치에 라이트를 배치하는 것입니다(motivated lighting). 이렇게 하면 반사 문제를 자연스럽게 해결할 뿐만 아니라, 씬의 사실성도 크게 향상됩니다.**
